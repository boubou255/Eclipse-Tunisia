# Eclipse-Tunisia

Vibes Trip – landing page & booking flow for the total solar eclipse of 2 August 2027 in Tunisia.

The front-end (React + Tailwind + Leaflet) lives in [`frontend/`](frontend/README.md):

```bash
cd frontend && npm install && npm run dev
```

The repository root is kept free for the future Laravel API (see `frontend/README.md` → "Plugging in the Laravel API").
